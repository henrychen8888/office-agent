# 02 · 资产条线 AI 提案（8 项 · 5月提报）

> 来源：`创新提案5月/`，提报单位为资产共享条线。
> 技术栈统一：**全部 8 项均基于 Dify 搭建**（工作流 / Chatflow / 数据库插件）。

## 类别 1 · 数据查询类（查 · 3 项）

| 提案 | 提报人 | 核心能力 | 技术方案 |
|---|---|---|---|
| 单位资讯资产与库存查询助手 | 刘敏（旺能） | 面向全单位，随时查看本单位人员资产及库存资产 | Dify 数据库插件连接外部库；ETL 同步 SAP 三类资产 → 自然语言查询工作流（意图识别 → SQL 生成 → 结果格式化） |
| 资产备件库查询智能体 | 黄燕林 | 跨单位查询闲置备件库存、位置、状态，为资产调拨提供依据，提高闲置利用率、减少重复采购 | Dify 内置数据库 + Chatflow（Agent + 查询工具 + 结果模板）；含 4 步实施工时表 |
| 资讯设备信息查询智能体 | 邢趁军 | 查询设备型号、预估价格，支持同品项不同规格对比，辅助选型 | Dify 工作流：开始（关键词）→ 代码执行（Python/Pandas 处理 Excel）→ LLM（对比分析）→ 结束（输出 Markdown 表格） |

## 类别 2 · 数据校验与对账类（核 · 1 项含 2 工作流）

| 提案 | 提报人 | 核心能力 |
|---|---|---|
| 智能数据自检工作流 | 蒋梦谣 | SAP 资产全流程自检 + 低耐台账对账 双工作流 |

**工作流 1 · SAP 资产自检**：上传 SAP 导出 Excel 并选定操作类型 → 自动输出含明细与统计的结构化异常报告
- 必填项缺失检测（资产名称、责任人、单据日期）
- 存放位置命名规范校验（楼栋-楼层-房间/区域）
- 业务逻辑判断（领用后状态需为「在用」；收回后应为「闲置」/「待入库」）
- 数值合理性核查（数量、原值、净值须为正数，杜绝负资产）
- 重复建卡 / 一物多码预警（资产名称 + 规格型号 + 存放位置组合键）

**工作流 2 · 低耐台账对账**：上传 SAP 清单 + 线下低值耐用品台账 → 自动比对
- 匹配规则：物品名称 + 规格型号 + 存放位置 三者联合唯一键
- 四类差异识别：数量差异 / 位置不符 / 有实无账 / 有账无实
- 输出：差异明细清单 + 分类统计 + 盘点整改建议

> 关联：工作流 1 支撑治理指标④标配管理健康度，工作流 2 支撑指标⑥账实相符率（见 `01-治理指标.md`）。

## 技术栈归纳

| 技术工具 | 出现场景 |
|---|---|
| **Dify** | 全部 8 项提案的统一搭建平台（工作流 / Chatflow / 数据库插件） |
| Python + Pandas | Excel 数据处理、模糊搜索、结构化输出 |
| LLM | 字段识别、业务逻辑判断、智能对比分析 |
| BPM / HTTP API | 智能体与业务系统交互（如资讯申请单选型） |
| ETL / 中间件 | SAP 数据导出与持续同步 |
