## 三、字体规范（分级）

### 3.1 字体名写法（实测，注意区分层）

模板里的字体名**是分层的、且不统一**——这是实测发现的关键细节：

| 层 | 字体名写法 | 出现位置 |
|---|---|---|
| **版式层** | `微软雅黑`（中文名） | slideLayout 的 lstStyle/defRPr |
| **内容页正文层** | `Microsoft YaHei`（英文名） | 内容页 P4/P6/P7 的表格与文本框 |
| 首页装饰 | `Arial Black`（majorFont_latin） | 版式装饰英文 |
| 结束页 | `Arial` | 6_结束页 |
| 主题 minorFont | `微软雅黑` | theme1 的 minorFont latin/ea |

> **生成时按层选择**：版式继承部分不用管（随版式走）；**内容页的文字统一用 `Microsoft YaHei`**，以对齐模板正文层。
>
> 注意：模板自身还残留了 `等线`、`+mn-lt`（主题引用）、`Noto Sans SC`（外部字体，从 HTML 带入），属历史遗留，**不建议照搬**。

## 八、生成新 PPT 时必须遵守

1. **画布 16:9（25.4 × 14.29 cm）**，不得用 4:3
2. **全篇微软雅黑**，西文同样用微软雅黑（除结束页 Arial）
3. **颜色只用主题色板内的值**，强调数字用 `#FFFF00`，关键值用 `#0432FF`，正文用 `#1A1A1A`
4. **字号严格按第三节分级**，不得自创字号
5. **首页/目录/节标题/结束页必须用满版背景图版式**，内容页用白底
6. **内容页表格宽度固定 24.08 cm**、7 列结构，不擅自增删列
7. **章节结构固定为三章**（OGSM 达成 → 重点工作 → 其他关注）
8. **节标题页保留大号章节序号数字**（103.5pt）
9. **页脚三件套保留**：日期 / 页脚 / 页码
10. 未达标项必须给「分类 + 原因 + 改善」三列，不得只列问题

## 十、推荐的生成方式

**首选**：以 `月报模板v3.pptx` 为基底模板，替换文字与表格数据，保留全部母版/版式/配色。

**次选**：用 python-pptx 从模板复制版式生成，套用本规范的字体、字号、色值常量。

**禁止**：新建空白演示文稿后自行设定字体颜色——会丢失母版继承关系与背景素材。

## 十一、垂直网格（排版对齐的核心）

> 只记单页绝对坐标不够——内容元素个数会变。必须归纳出**可套用的网格**。

从 3 个内容页（P4/P6/P7）归纳出的实测网格：

| 网格项 | 值 | 来源 |
|---|---|---|
| 标题 Y / 高度 | **0.42 / 0.98** | 内容页标题占位符 |
| **正文起始 Y** | **2.37 ~ 2.39** | 首个表格/卡片的 y，全篇一致 |
| 左边距 | 0.92 | 内容元素最小 x |
| 内容区宽度 | 24.08 | 内容元素最大右边界反推（右边距 0.40） |
| **正文下界** | ~12.6 | 内容元素最大下边界 |
| **底部留白** | **1.32 ~ 2.39** | 画布高 14.29 减正文下界 |
| 页脚带 Y | 13.24 | 日期/页脚/页码三占位符 |

**版面饱满度的判据就是这个「底部留白」值**：模板始终维持在 1.3~2.4，意味着内容要铺满到接近页脚。若生成结果留白超过 3 cm，就是垂直节奏没对齐。

### 均分函数

样式库 `scripts/pptx_style.py` 提供：

```python
S.GRID                       # 上述网格常量
S.vgrid_rows(n)              # 把正文区按 n 行均分，返回 [(y, h), ...]
S.vgrid_rows(n, top, bottom) # 自定义区间
S.content_title_y()          # 标题的 (x, y, w, h)
```

`vgrid_rows(5)` → 行高 1.82、末行底 12.60、留白 1.69（与模板一致）。

### 踩到的坑（已修正）

1. **卡片高度不足**——系统建设类含 5 项待办，卡片按 4 项高度设定，第 5 项溢出压到下方卡片。修法：`rh = (h - 表头) / len(items)`，按实际条目数均分。
2. **多段落容器被误判溢出**——检查脚本把同一文本框内所有段落累加行数，导致多段落标题被误报。检查时应**按段落分别计算**，取最大者与容器容量比较。
3. **大字号与多行同容器**——26pt 数值与说明文字放同一容器会挤。修法：拆成独立文本框，按纵向位置分段排布。
4. **垂直节奏未对齐（最主要）**——见上表 v1→v2。
