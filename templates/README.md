## 三、通用排版规范（所有模板适用）

| 项目 | 规范 |
|---|---|
| 纸张 | A4 |
| 正文字体 | 宋体 |
| 首行缩进 | 2 字符 |
| 地区表述 | 使用「中国台北」 |
| 措辞风格 | 中性管理语言，不用「领导」等称谓 |
| 导出格式 | PDF（打印/提交）/ Word（需修改）/ Markdown（归档） |

## 五、PPTX 格式规范（独立体系）

> 见 `pptx-format-spec.md`。**后续所有生成的 PPT 必须套用此规范。**

来源：`桌面/月报模板v3.pptx`（10 页 / 16:9）

| 项目 | 规范 |
|---|---|
| 画布 | 25.40 × 14.29 cm（16:9） |
| 字体 | 微软雅黑（西文同用）；结束页 Arial |
| 主色 | 深蓝 `#0E2841`、主强调 `#156082` |
| 强调色 | 达标率 `#FFFF00`、关键值 `#0432FF`、正文 `#1A1A1A` |
| 结构 | 封面 → 目录 → 三章（节标题+内容页）→ 结束页 |
| 内容页表格 | 固定 7 列，宽度 24.08 cm |

**可复用资产**：

| 文件 | 用途 |
|---|---|
| `pptx-format-spec.md` | 完整格式规范（母版/字体/颜色/排版逐页说明） |
| `scripts/pptx_style.py` | 样式常量库，生成时直接 import |
| `scripts/build_monthly_ppt.py` | 月报生成脚本（以模板为基底） |
| `scripts/extract_pptx_format.py` | 从任意 PPTX 提取格式要素 |
| `_pptx_format_raw.json` / `_pptx_themes.json` / `_pptx_layouts.json` | 原始提取数据 |

**生成原则**：以 `月报模板v3.pptx` 为基底复制生成，继承母版与背景素材；**禁止**从空白文档重建。
