# 个人办公智能体 · 发布版 v1.0.0

> 独立可分发制品。解压后**双击 `console.html` 即可使用**，无需安装、无需联网、无需服务端。

## 快速上手

1. 解压本包
2. 双击 `console.html`（推荐 Chrome / Edge / Safari）
3. 左侧导航切换功能区，工作台默认展示今日概览

## 功能导航

| 页面 | 能做什么 |
|---|---|
| 工作台 | 今日概览、快捷指令、最近动作、推送场景概览 |
| 模板库 | 10 套公文/报告模板在线填写，一键生成正文并复制 |
| 记忆库 | 五层记忆（身份/偏好/关系/事实/事件）增删改查，本地持久化 |
| 知识库 | 6 项资产治理指标、8 项 AI 提案、基线口径、分类框架，可搜索 |
| 主动感知 | 6 类推送场景开关与时间配置 |
| 授权规则 | 五级授权模型 + 动作归属速查（可搜索） |
| 审计日志 | 动作记录、按等级筛选、手动补录 |
| 模块规划 | 模块状态与实施路径 |

## 数据存储

全部数据存于**浏览器 localStorage**，不落服务端、不上传。换浏览器或清缓存后记忆与审计记录会重置，重要内容请另行归档。

## 部署到内网

把 `console.html` 单文件复制到任意内网静态目录即可，例如 `http://<内网IP>/console.html`。

## 本发布版说明

- **知识库为脱敏版**：保留指标口径、公式、阈值与治理方法，**不含**四区在账台数、比例数值与内网地址。基线数值请对照当期资产看板获取。
- 阈值权威源在 `memory/thresholds.md`，改动阈值后同步 `console.html` 内的 `THR` 常量。
- 知识文件与工作台内容需同步维护：先改 `knowledge/` 下的 Markdown，再同步 `console.html` 内的 `KNOW` 常量。

## 安全边界

- 外部动作（发邮件、发群消息、发起会议邀请）**必须二次确认**
- 数据变更（数据库增删改、删除文件）**一律不做**，需人工执行
- 含业务数据的文书**不出内网**
- 地区表述统一使用「中国台北」
- 审计记录可查，智能体无权自行删除
